# ⚡ EVYatra – Smart EV Charging Platform

EVYatra is a web platform designed to make electric vehicle journeys easier and smarter in India. It helps EV owners discover nearby charging stations, compare charging prices, check charger availability, and explore EV-related information.

## 🚀 Features

- 📍 Find nearby EV charging stations.
- 🔋 Explore charger types and charging power.
- 💰 Compare charging prices.
- ⚡ Check charging station availability.
- 🚗 Explore electric vehicles and EV-related information.
- 📱 Responsive and user-friendly interface.

## 🛠️ Tech Stack

- **Frontend:** Next.js 14, React 18
- **Language:** TypeScript, JavaScript
- **Styling:** CSS, Tailwind CSS
- **Icons:** Lucide React
